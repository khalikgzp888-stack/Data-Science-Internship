# Week 5 – Comprehensive Data Science Project

## Overview

This is the final project of my Virtual Data Science with Python Apprentice Internship. The project integrates the data science techniques learned throughout the internship using the Titanic dataset.

## Objectives

- Integrate the work completed during previous weeks.
- Perform data cleaning and exploratory data analysis.
- Analyze patterns using data visualization.
- Perform statistical hypothesis testing.
- Develop and evaluate a machine learning model.
- Identify key findings and provide strategic recommendations.
- Discuss business/research impact, limitations, and future improvements.

## Dataset

**Dataset:** Titanic Dataset  
**Source:** Kaggle  
**Records:** 891  
**Columns:** 12

## Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- SciPy
- Scikit-learn

## Analysis Performed

### Week 1
- Data acquisition
- Data cleaning
- Missing value handling
- Exploratory Data Analysis

### Week 2
- Advanced data visualization
- Survival analysis by gender and passenger class
- Fare distribution
- Age vs Fare analysis
- Survival analysis by embarkation port

### Week 3

- Chi-Square Test of Independence
- Statistical interpretation

### Week 4
- Logistic Regression
- Feature selection

- Confusion Matrix

### Week 5
- Project synthesis
- Key findings
- Strategic recommendations
- Business impact and research outcomes
- Limitations
- Future improvements
- Final conclusion

## Key Results

- Chi-Square value: **260.72**
- p-value: **1.20 × 10⁻⁵⁸**
- Logistic Regression Accuracy: **75.52%**
- AUC: **0.81**
