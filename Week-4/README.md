# Week 4 – Machine Learning Model Development and Evaluation

## Overview

This week focused on developing and evaluating a Machine Learning classification model using Python. The Titanic dataset was used to build a Logistic Regression model for predicting passenger survival.

## Objectives

- Understand the basic workflow of Machine Learning.
- Prepare data for model training.
- Split the dataset into training and testing sets.
- Train a Logistic Regression model.
- Make predictions using the trained model.
- Evaluate model performance using different metrics.
- Visualize the model results using a Confusion Matrix and ROC Curve.

## Tools and Technologies

- Python
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn
- Jupyter Notebook

## Tasks Performed

- Loaded and prepared the Titanic dataset.
- Selected relevant features for prediction.
- Encoded the categorical `Sex` feature.
- Split the data into training and testing sets.
- Trained a Logistic Regression model.
- Generated predictions on the test data.
- Calculated model accuracy.
- Created a Confusion Matrix.
- Created an ROC Curve and calculated AUC.

## Model Result

The Logistic Regression model achieved an accuracy of approximately **75.52%** on the test dataset.

The ROC Curve analysis produced an **AUC of approximately 0.81**.

## Key Learning

This week helped me understand the complete Machine Learning workflow, from data preparation and model training to prediction and performance evaluation.
