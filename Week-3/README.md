# Week 3 – Statistical Analysis and Hypothesis Testing

## Overview

This week focused on statistical analysis and hypothesis testing using Python. The objective was to understand relationships between variables and use statistical methods to support data-driven conclusions.

## Objectives

- Understand basic statistical concepts.
- Perform statistical analysis using Python.
- Formulate Null and Alternative Hypotheses.
- Apply the Chi-Square Test of Independence.
- Interpret statistical results and p-values.
- Support findings using data visualization.

## Tools and Technologies

- Python
- Pandas
- Matplotlib
- Seaborn
- SciPy
- Jupyter Notebook

## Tasks Performed

- Loaded and prepared the Titanic dataset.
- Selected relevant variables for statistical analysis.
- Created a contingency table.
- Performed Chi-Square hypothesis testing.
- Analyzed the relationship between gender and survival.
- Created visualizations to support the findings.
- Interpreted the statistical results.

## Key Learning

This week helped me understand how hypothesis testing and statistical analysis can be used to identify meaningful relationships in data and make evidence-based conclusions.
